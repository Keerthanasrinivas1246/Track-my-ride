About Track My Ride

An intelligent, location-aware productivity system engineered to eliminate forgotten errands through precision background geofencing and responsive web technologies.

The Problem

Traditional to-do apps notify you based on clock time (e.g. 5:00 PM). But real life is bound by geography. If you are scheduled to buy groceries at 6:00 PM but you happen to drive past the supermarket at 4:30 PM, standard apps stay silent. Worse, if you pass within 100 meters of an errand location on your commute home and forget, you must make a frustrating return trip.

The Smart Solution

Track My Ride attaches geodetic coordinates, venue metadata, and custom radius boundaries to every task. By executing the Haversine trigonometric distance formula through continuous background geolocation polling, the app triggers proactive alerts (browser notifications, in-app banners, and audio chimes) the exact instant you breach the target radius.

System Architecture & Modular Django Structure

The backend is structured into decoupled, single-responsibility Django apps to ensure high cohesion, low coupling, and seamless horizontal scalability:

accounts app

Handles user registration, authentication, password recovery, profile preferences (preferred radius, avatar, audio toggle), and strict user task data isolation.

tasks app

Manages full CRUD operations, category taxonomy, priority levels (Low, Medium, High, Urgent), status pipelines, calendar feeds, and CSV spreadsheet exports.

maps app

Coordinates Google Maps JS API, Place Autocomplete, draggable pin geocoding, radius circle visualizer, and the full interactive map canvas with custom markers.

notifications app

Implements the live Geofence Proximity engine. Executes Haversine calculations, prevents notification spam via cooldown windows, and stores reminder logs.

contact app

Captures user inquiries, feedback, and support tickets with database persistence and Django admin resolution workflows.

core app

Orchestrates public landing pages, analytical command dashboard, global template context processors, and aggregate metric calculations.
